## 更正窗口继续展示旧记录

原实现仅在切换范围、关闭或手动刷新时清空结果。窗口打开后，作业撤回或再次编辑，即使主作业板已更新，更正窗口仍保留旧记录；尚未返回的旧更正请求也可能被接受。

修复后以作业 ID、修订号、发布状态及列表读取状态标识本次快照。接收到变化时取消请求、使旧响应失效、清空记录，并提示“作业已变化，请刷新更正回顾后重新核对”。初次读取作业列表期间不误触发失效；若请求已被另一轮尚未结束的刷新替代，要求稍后重试。

新增两项浏览器测试，分别覆盖已经展示后的撤回，以及请求延迟期间再次编辑。修复前两项均失败；修复后两项通过。真实 PostgreSQL 全链路测试另验证撤回后无需点击刷新，窗口即移除旧内容。

限制：窗口依据客户端实际收到的作业变化失效，无法在服务器发生变更的同一瞬间获知；此机制不代替后端访问校验。

## 非法日期异常与日期规范化不一致

共享日期解析函数对无效月份等输入直接调用 `toISOString()`，会抛出 `RangeError`，绕过正常参数错误处理。更正接口还存在校验时去除首尾空格、查询时使用原字符串的问题。

修复后先检查日期有效性，再比较标准日期；更正查询统一使用解析后的日期构建北京时间范围。单元测试覆盖零月份、超范围月份/日期、二月无效日期以及带空格的合法日期。修复前新增单元测试复现异常；修复后通过。真实 HTTP 测试验证更正接口非法日期返回 400，合法日期带空格时与标准输入返回相同结果。
