# 作业更正提示与清单图片

## 大屏更正提示

大屏收到新的作业列表后，与本页面已显示过的内容比较。在同一日期、绑定和班级范围内，更正标题、正文、科目、发布班级、截止时间或无作业状态时，显示醒目提示。首次出现的作业只正常展示，不触发更正提示；之后修改这项作业，才会与此前显示的内容比较。“先标记无作业，后来新增作业”的冲突仍由各科录入状态提示。

提示默认保留两分钟，可手动收起。摘要展示修改前后内容，长文字会提取变化附近的片段，可展开查看完整内容。连续更正同一项时保留首次变化前的内容，并显示最新结果。更正又恢复成原内容时，取消该项提示。

首次打开、重新加载页面、切换日期、切换大屏绑定或班级范围时建立新基准，不把全部现有作业当作更新。仅教师确认状态变化不触发更正，也不会延长提醒时间。缓存回退不会覆盖已知的新版本；恢复联网后可与先前显示的内容比较。

提示依据本机已读取的列表，并非完整审计记录，不推断列表中消失的记录已被撤回；提示仍注明“教师已确认”或“待教师确认”。历史记录继续从每项作业的历史入口查看。比较基准只保存在页面内存中，限制为最近 500 项；不写入本地存储，不额外请求历史接口。

## 生成 PNG 清单

1. 学生页点击“打印作业清单”，或大屏“更多 → 打印作业清单”。
2. 在预览中点击“生成清单图片”。
3. 长内容自动拆成多张图片，每张都有页码；逐张点击“保存第 N 张 PNG”，分享时包含所有页。

图片沿用打开预览时的固定数据，包含所选班级、日期、科目、正文、截止时间、优先级、教师确认状态和数据更新时间。每页重复班级范围、日期、离线缓存和未上传作业提示。“今日无作业”保留为明确标记，不计入普通作业数量。

生成使用浏览器本地 Canvas，不上传正文、请求第三方图片服务或加入新依赖。输出为 1200×1600 PNG。按照实际字体宽度换行，保留空行和完整文字，超长单条作业可跨页。最多 100 张，超过上限会明确报错，不输出截断清单。

图片工具按需加载并纳入 PWA 预缓存，已安装应用在离线时也可首次生成已缓存的作业清单。关闭预览、切换范围或卸载组件会取消正在生成的任务，并释放所有临时图片 URL。打印与 PDF 入口仍然可用。
