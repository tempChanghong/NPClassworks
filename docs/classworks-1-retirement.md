# Classworks 1 源码退役边界

NPClassworks 不迁移官方 Classworks 服务器上的旧 UUID 作业数据。当前生产系统只使用学校组织、账号、教学空间、Publication 和班级大屏链路。

已物理删除：

- C1 首页附属组件、旧列表和旧缓存管理页面；
- UUID/KV 登录、设备授权和云端轮换前端；
- C1 KV 数据提供器、同步队列和设备事件转发；
- 后端独立的 KV、应用安装、UUID 设备、设备授权和自动授权路由模块；
- C1 token/UUID Socket 房间和任意事件转发。

刻意保留：

- `/accounts` 中 C2 使用的本地登录、OAuth、Token、资料和教师偏好；
- 与 C2 账户路由同文件的历史 `/accounts/devices*` 处理器暂不强拆，但应用中间件与网关都会先返回 410，请求无法进入旧处理器；
- workspace Socket 房间及作业/通知失效事件；
- 大屏本地离线队列、噪声监测和当前设置；
- Prisma 历史迁移和遗留数据库表，避免破坏全新安装、升级与回滚。

网关对已退役的 C1 HTTP 路径返回 410。不得为了“清理干净”修改已经发布的 Prisma 历史迁移；未来删表必须使用新的、可审计的迁移并单独评估回滚策略。
