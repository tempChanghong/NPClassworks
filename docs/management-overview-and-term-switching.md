# 管理总览与学期切换

## 管理总览

学校管理员进入“管理总览”后，可按学校和学期查看：

- 年级、行政班、走班教学班、任课教师和大屏数量；
- 任课关系、年级组长/班主任职责、大屏设备、账号与学期结构异常；
- 错误和提醒数量，以及对应配置页面的处理入口。

“错误”通常表示会影响实际授权或新学期启用的结构问题；“提醒”表示系统仍可运行，但建议管理员核对。

## 学期切换流程

1. 在“学期运维”选择当前学期，填写下一学期名称、学年、序号和日期。
2. 选择要继承的教师访问权限、任课关系、管理职责和待认领 OAuth 邀请。
3. 执行“预检迁移内容”，确认复制数量和提示。
4. 建立草稿学期，在“组织与班级”“授课结构”“教师分配”中完成调整。
5. 返回“学期运维”点击“启用”，检查阻断项和大屏迁移预览。
6. 确认启用后，旧学期自动归档；大屏默认按行政班代码迁移到新学期对应班级。

无法按班级代码匹配的大屏不会被错误绑定，管理员应在“大屏设备”中手动处理。强制启用只用于确认阻断项暂时可接受的情况，不会忽略未匹配大屏的提示。
