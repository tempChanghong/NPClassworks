# 任课教师通知误标为待确认

日期：2026-09-09。

## 原因与修正

后端账号发布、修改、复制、恢复历史共用确认计算。原规则只接受管理职责或匹配的任教学科，普通任课教师发布的通知没有 `subjectId`，因此得到了 `isCertified: false`。前端按后端字段显示待确认，错误源头不在标签或提示音。

确认计算归入 `publicationAuthorizationService.js`：通知在调用者提供的事务中检查所有目标的发布权限，通过后以当前保存账号记录确认信息。作业仍使用原任教学科/管理职责规则。大屏不能提交通知的限制保持不变。

数据迁移 `20260909000000_account_notice_certification` 只修正已发布通知的当前版本，要求当前操作和版本记录都来自账号、版本快照也是已发布通知、正文未清理且编辑账号仍存在。当前记录与对应版本一起修正，确认时间取该版本创建时间；不改正文、发布时间、更新时间、版本号或更早历史。没有可靠来源的记录不自动确认。迁移可重复执行，现有 Docker 启动命令已运行 `prisma migrate deploy`，无需修改部署代理。
