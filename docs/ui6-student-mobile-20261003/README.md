# UI.6：学生手机端空作业日布局修正

依据 2026-10-03 的手机截图，修正了四个能直接观察到的问题：日期标题挤成多行、原生日期输入框被裁切、各科录入状态重复出现，以及默认空状态的图标和标题过大。截图中的自定义壁纸还会透过半透明卡片干扰阅读。

- 紧凑日期栏改为上下两行：前后日期和标题在第一行，“今天”与完整日期输入框在第二行；320px 宽度下仍保留完整日期和可点击区域。
- 有尚未录入／冲突科目时，把唯一的可展开状态放在内容之前；没有需注意项目时，才在内容之后显示普通状态。空作业日不再重复同一条摘要。
- 手机空状态使用较小的图标和常规标题，并收紧卡片高度；班级、日期、状态与空状态卡片在自定义壁纸上使用高不透明度表面，保持文字可读。

合成亮色壁纸与 2026-10-01 空作业日的复核截图：[390px](student-empty-390.png) · [320px](student-empty-320.png)。这些是本地 Chromium 触摸视口截图，不是用户设备截图，也不代表 Android 系统字号、原生日期控件和浏览器版本的真机验收。

本地验证：生产构建、修改文件 ESLint、`git diff --check` 和学生页／日期导航／大屏布局相关的 22 项浏览器回归通过。新增回归检查日期标题不折行、输入框不越界、状态只出现一次、空状态高度与壁纸下的卡片背景不透明度。
