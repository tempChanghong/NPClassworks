# Classworks 2.0 第五阶段 D：无邮箱登录界面

教师工作台 `/classworks-2` 现在优先显示“学校 + 教师短账号 + 个人 PIN/通用口令”，OAuth 仅在学校配置允许时显示。学生查看作业仍不需要登录。

学校管理页 `/classworks-admin` 新增：

- 首次部署管理员创建：服务器一次性初始化密钥、学校代码、管理员短账号和个人 PIN。
- 学校认证策略：个人 PIN、学校通用口令、OAuth 邮箱，以及 OAuth 备用入口。
- 本地教师创建与分配：短账号、姓名、PIN 和多个行政班/走班教学班一次完成。
- 批量 JSON 导入：本地账号模式使用 `username`、`name`、`pin`；OAuth 模式继续使用 `email`。

推荐使用个人 6 位 PIN。学校通用口令虽然最省事，但无法阻止知道口令的学生冒用其他教师，只适合作为明确接受风险后的极简选项。
