# 明日要交与需带

学生页、大屏及教师工作台新增“明日要交与需带”入口。教师先选择已授权的教学空间；学生和大屏沿用当前班级范围。打开后自动联网读取，展示放学前核对清单，也可手动刷新。

## 清单范围

- **明日要交**：按北京时间实际明天的截止日期筛选，与正在翻看的作业板日期无关。更早布置的作业也会被纳入，按截止时间排列，显示科目、原作业日期、正文、选做内容、提交说明及教师确认状态。
- **明日需带**：合并现有需带物品数据，只显示携带日期为明天的记录，包括更早布置的准备事项。
- **今日作业 · 截止未设置，请核对**：仅列今天作业板上未设置截止时间的普通作业，明确提示不能确定是否明天要交。更早的无截止日期作业不在这一栏内，需要查阅历史。

“明天”指下一个自然日，不推断周末、节假日或下一上课日。没有符合条件的已发布记录时，提示当前查询未找到相关内容，不把它等同于教师已明确声明无作业。草稿、未到发布时间、已撤回、其他班级内容及无作业标记不纳入待交清单。无需教师重复录入。

## 打印与图片

“打印作业清单”打开固定快照，可通过系统打印窗口保存 PDF，或生成分页 PNG。打印和图片保留明日要交与截止未设置的分组，包含明日物品、提交说明、选做内容及确认状态。长正文完整分页，错误时不会输出部分清单。

范围说明随导出保存。本机尚未上传的作业不在清单中；存在待上传内容或队列读取异常时另行提示。

## 数据与状态

复用已有完整日作业列表（含需带物品）和按截止日期查询的周接口，逐页读取后筛选明天。不扫描所有历史作业，也不新增后台定时查询；日查询与截止查询可并行。

任一查询失败会清空清单并隐藏导出入口。关闭、换班、账号或绑定切换会取消旧请求，晚到结果不会覆盖新范围。窗口打开时监听现有发布事件，包括当前作业板日期之外的作业变化；收到变化或重新连接后清空快照并提示刷新。关闭时释放监听。跨日检查仅在窗口打开时每分钟执行，也在页面可见性变化时核验日期。

读取日列表、需带物品和截止日期各分页时，若发现同一作业修订号不一致，会要求重新刷新，避免将不同版本拼成一份矛盾清单。通知变化不属于作业变化：正常收到通知并刷新列表时，保持核对清单和已打开的导出预览。

发布时间按所有查询返回后的时间判断，避免将请求进行期间刚发布、已由服务器返回的作业或需带物品误删；仍未到发布时间的内容继续排除。查询日期仍取打开本次查询时的日期，跨日结果由窗口的日期检查丢弃。

这是按需读取的快照，不保证两次查询构成同一数据库事务，也不保证能即时获知断网期间的服务器变化。首次打开及手动刷新需要联网；纸质或已保存图片以生成时内容为准。
