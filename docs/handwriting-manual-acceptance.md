# 手写正文人工验收

这是本地验收入口，不是部署。使用正式前端、真实 KV 和自有临时 PostgreSQL；测试学校、班级、凭证与真实学校无关。需要本机开发依赖、原生 PostgreSQL 工具和 Edge（Linux 用已安装的 Chromium）。不要求在学校一体机上安装这些开发依赖；没有独立测试环境时，学校 PWA 的实测仍待后续安排。

## 开始与结束

在 NPClassworks 根目录运行：

```powershell
# 默认后端为相邻 NPClassworksKV。可指定另一个已安装依赖的只读候选工作树：
# $env:CLASSWORKS_BACKEND_ROOT = 'D:\CodeProjects\Research\handwriting-integration-kv-main-20261020'
# 非默认 PostgreSQL 目录可设置：
# $env:NPEP_TEST_PG_BIN = 'C:\Program Files\PostgreSQL\17\bin'
pnpm run test:handwriting:manual
```

首次准备需等待构建。随后打开“大屏”和“教师”两个临时独立浏览器窗口，已选好数学与高一一班。教师端另有高一二班，可检验切班。窗口使用隔离会话，不接触日常浏览器账号，不需要输入学校地址或真实管理口令。

正常结束时，关闭**两个角色的全部验收标签页**，包括为冲突检查新开的标签页。遇到未保存提示，先决定保留文字还是放弃；结束后等终端打印 `HANDWRITING_KV_RESULT`。会话最长一小时，结束或超时后启动器尝试关闭本次服务、停止临时 PostgreSQL 并恢复生成客户端。不要用任务管理器直接终止启动器；若电脑断电或整个终端被强杀，不能保证清理代码执行，需核查本次 `result.json`，不能按已清理处理。

成功结束会清理临时库，测试作业不作为真实作业保留。源码不应在会话期间修改或 Commit，否则源码指纹检查会失败。失败时保留已停止集群供诊断，不操作其他数据库或浏览器缓存。

仅验证启动流程、无需打开可见窗口时运行：

```powershell
pnpm run test:handwriting:manual:smoke
```

冒烟只验证临时库、真实页面、两个角色入口与未识别时不启动模型，不替代真人识别、物理触控或安装 PWA 验收。它和人工入口均不加入普通 CI 用例集合。

## 缩放与设备记录

- 网页和 PWA 的**页面缩放使用 100%**。不为此次验收强制叠加 200% 页面缩放。
- Windows 显示缩放与页面缩放不同：保留设备原有设置，只记录它，检查实际可用窗口大小、按钮可达性和触控落点。无需为了测试改变一体机分辨率或 Windows 缩放。
- 本入口不指定 DPR2、模拟触屏或固定 CSS 窗口；自动化 DPR2 的历史结果不能代替这里的实测。
- 两个窗口是临时隔离浏览器会话，**不代表已安装 PWA**。已安装 PWA 需另用获准的测试站点及测试账号，在正常浏览器配置中完成安装、独立窗口、离线与更新检查；本入口不会安装 PWA 或建立真实学校账号。

记录设备型号、Edge 版本、分辨率、Windows 缩放、页面缩放、网页/PWA、键盘/手指/笔。不要写真实学生姓名或其他敏感内容。

## 记录与指标的含义

每次输出目录为 `.artifacts/handwriting-kv/<编号>/`，终端显示完整路径：

- `result.json`：源码 SHA、模式、浏览器运行结果和清理情况。`PASSED` 只表示对应自动检查或会话正常结束；人工结果始终为 `humanAcceptance: PENDING`，不会代填上表。
- `browser/manual-session.json`：准备阶段、会话模式、页面错误计数、保存记录的编号/版本/状态，以及最近最多 200 次数字计时。该报告不采集笔迹或识别正文，截图、视频、trace 和失败页快照也关闭；真实作业保存到临时库中的仍仅为确认文字。后端仍保留原有错误诊断日志，因此验收只输入测试材料。
- 数字计时里的 `workerRoundTripMs` 从向推理 Worker 投递开始，到返回结果结束，**不含资源准备和主页面预处理**；`modelMs` 是模型阶段。两者不能当作用户点击到可编辑结果的全流程耗时。重开、刷新或额外标签页的工作线程计数只是各页面观察值，不是整个浏览器进程统计。
- 内存用 Edge 浏览器任务管理器另记空闲、识别期间、关闭后的范围；记清哪些进程被计入，不把 JS 堆、资源大小或两种角色同时打开的总量当作单次识别成本。测某个角色时，另一角色不要同时保持识别模型运行。不能用强制 GC 或清缓存制造低内存结果。

填完操作表并记录设备、问题与指标后，才讨论人工通过与 PR。启动冒烟和模拟触控通过不能替代人工结论。
