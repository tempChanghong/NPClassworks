# Classworks 首次进入与登录指南

Classworks 对学生、教师和班级大屏采用不同的首次进入方式。学生不需要账号；教师使用学校发放的短账号；大屏由管理员一次性绑定，日常不需要任何人登录。

## 0. 学校首次部署

这一步只由系统首位 OWNER 完成一次。

1. 服务器管理员先在服务器配置 `BOOTSTRAP_SETUP_KEY`。
2. OWNER 打开 `/classworks-admin`。
3. 页面显示“首次部署：创建首位管理员”时，填写学校代码、管理员姓名、管理员短账号、4～8 位数字 PIN 和服务器一次性初始化密钥。
4. 点击“创建并登录”。
5. 在管理页导入或建立学期、年级、行政班、科目规则和走班教学班。
6. 创建教师短账号并分配教学空间，下载一次性凭据 CSV 后交给教师。

完成学校和当前学期初始化前，学生无法正确选班，教师也不会拥有可发布的教学空间。

## 1. 学生首次进入

学生不注册、不登录，也不需要密码。

1. 打开 Classworks 根地址 `/`。
2. 首次进入会自动打开“选择我的班级”。
3. 选择学校和行政班。
4. 只为自己实际参加的走班科目选择教学班。
5. 点击保存后即可查看作业。

按当前七班制模板，一、四班的物化生全部随行政班；二班的政治、三班的物化以及五至七班各自定科也不需要重复选择，其余小科按学校配置显示对应走班教学班。

选班结果保存在当前浏览器。学生更换设备、使用无痕窗口或清除网站数据后，需要重新选择，但仍不需要账号。

## 2. 教师首次进入

推荐登录方式是“学校 + 教师短账号 + 个人 PIN”。

1. 教师在自己的手机或电脑打开 `/`。
2. 点击顶部“教师”。
3. 选择学校，输入管理员发放的教师短账号和个人 PIN。
4. 登录后自动看到自己负责的所有行政班和走班教学空间。
5. 建议首次登录后修改个人 PIN。

登录状态默认在该设备保留 180 天。连续输错只会暂时限制本设备对该账号的继续尝试，不会把教师账号全局锁定。学校如果初始化时选择了“全校通用教师口令”或 OAuth，登录框会按学校配置显示对应方式，但推荐方案仍是个人 PIN。

教师不应在已经绑定的班级大屏上登录工作台；已绑定设备只显示大屏界面。

## 3. 班级大屏首次进入

大屏没有供师生日常输入的账号。它使用管理员首次绑定后保存在浏览器中的大屏令牌。

首次绑定步骤：

1. 在尚未绑定的教室一体机浏览器打开 `/`。
2. 点击“教师”，使用 OWNER 或 ADMIN 的学校短账号和 PIN 登录。
3. 切换回“看作业”，选择这台一体机所属的行政班。
4. 点击“绑定为本班大屏”。
5. 绑定成功后，系统保存大屏令牌，并自动退出管理员账号。
6. 页面立即进入大屏模式；之后刷新或重新打开网站仍只显示大屏界面。

大屏日常不需要教师、学生或管理员再次登录。它可以查看绑定行政班及相关走班作业，并使用大屏录入、历史版本和课堂工具。

不要清除一体机浏览器的网站数据，否则大屏令牌会丢失，需要管理员重新执行绑定。更换浏览器、重装系统或更换一体机时也需要重新绑定。

## 4. 账号与设备关系

| 使用者 | 是否登录 | 首次需要什么 | 状态保存位置 |
| --- | --- | --- | --- |
| 学生 | 否 | 学校、行政班、个人走班选择 | 当前浏览器本地 |
| 教师 | 是 | 学校、短账号、个人 PIN | 账号会话，默认 180 天 |
| 班级大屏 | 一次性绑定 | OWNER/ADMIN 临时登录并选择行政班 | 当前一体机浏览器的大屏令牌 |
| 首位 OWNER | 是 | `BOOTSTRAP_SETUP_KEY`、学校代码、短账号、PIN | 管理员账号与会话 |

管理员停用某台大屏绑定后，该设备的大屏令牌立即失效，并恢复普通浏览器的学生/教师入口。
