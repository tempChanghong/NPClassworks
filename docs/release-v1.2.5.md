# NPClassworks v1.2.5 · Hitori（后藤一里）

## 版本概述

v1.2.5 是基于 v1.2.0 的配对、定时监测展示、界面及安全更新，沿用代号 **Hitori（后藤一里）**，按正式版发布。配套 **NPClassworksKV v1.2.5** 与 **NPEduTools v1.0.0 · EVA-01（初号机）**。

本版重点让学校预先开放大屏配对，让定时监测有独立、清楚的展示页面，并改善学生、教师、大屏及学校管理的布局。v1.2.0 已有的通知、考试／日常切换、考试方案与原生噪音报告继续保留；本版不是重新推出这些功能。

## 新增功能

### 预授权配对：管理员不必同时在线

- 学校后台可以提前对已有班级大屏开放 NPEP 配对，也可按当前学期的年级或全校批量处理；先预览范围，再确认提交。
- 被授权的大屏网页可生成 **8 位、10 分钟有效的一次性配对码**，同时显示供 NPEduTools 使用的后端地址。桌面输入后确认固定的学校、班级和设备归属，管理员无需实时批准。
- 保留原有“桌面申请、学校管理员批准”的流程。关闭预授权不会撤销已经配对的设备；未来新建的大屏也不会自动继承本次批量开放。
- 范围或授权发生变化时要求刷新并重新确认，不自动把旧预览应用到新名单；已经被占用的大屏不被新配对替换。

### 定时监测独立页面与限时返回

- 原生桌面实际开始定时采集并上报可信状态后，网页进入专用监测画面，集中显示电平、采样质量、时段、状态和来源。仅有规则或“开始请求已受理”不会被当作正在监测。
- 作业板、通知和未提交草稿保留。可以暂时返回作业板，**返回不停止采集**；到期再自动返回监测画面。时长由学校后台配置，默认 **10 分钟**，范围 **1–60 分钟**。
- 停止定时监测使用学校管理 PIN 验证；手动监测维持原有启停方式。网页保护不是浏览器或 Windows 的锁定模式。
- 新增展示状态心跳，让桌面区分网页可见、暂时返回、隐藏、受阻及未知状态；不因为网页没有响应而误报采集已经结束，也不额外启动第二个网页麦克风。

## 体验优化

- 调整学生手机、教师工作台、班级大屏和学校管理的布局层级与响应式显示；改善大屏远距离阅读与操作入口。
- 优化考勤、作业录入、发布历史、通知中心、考试方案和噪音管理的列表、操作区域与结果提示，减少窄屏拥挤及状态混淆。
- 配对、设备状态、考试操作和监测报告分区展示，保留“请求受理”和“设备实际完成”的区别。
- PWA 不再预缓存无用的旧横幅；减少不使用的图标字体格式预加载。减少部分静态请求不等于所有设备首屏速度都提高。
- 关于页、恢复诊断和大屏上报统一读取包元数据，本版为 **1.2.5 / Hitori（后藤一里）**。

## Bug 修复与安全改进

- 修复空闲作业板没有当前时段或返回状态时的空值边界，避免页面因定时监测状态为空而崩溃；旧会话不能继续占用当前展示。
- 网络恢复事件早于连接真正可用时，允许有限重试，改善背景资源恢复。
- OAuth 登录交接绑定浏览器验证信息，并使用一次性换取流程；实时私有订阅按授权范围过滤，减少跨身份或跨范围的信息访问。
- 无关公开信息刷新不再误关闭已经打开的作业导出。
- 保留网页不收录元信息和既有访问控制；搜索引擎指令仍不能代替登录与权限验证。

## 升级说明

1. 先备份并更新 **NPClassworksKV v1.2.5**，应用完整 Prisma 迁移链并核对就绪状态，再更新网页，最后更新需要新保护能力的桌面至 **NPEduTools v1.0.0**。
2. 保留前端／API 分离配置。网页配对展示的是后端 API 地址；不要把前端网页路径填入 NPEduTools。已有 NPEP 部署身份及配对无需重新初始化。
3. 保存网页未提交内容后刷新或重新打开 PWA。通常不需要清空站点数据，以免丢失本机草稿、选班和绑定。
4. 预授权升级后默认不向未开放的大屏自动授权。使用批量操作前核对学期、班级、启用状态和预览范围。
5. 上线前核对学校定时时段、返回时长和管理 PIN。旧桌面在线不代表支持 0.8／0.9 保护与展示协议；应按设备实际能力判断。
6. 开发仍可使用 `pnpm dev` 统一启动前端与原生 PostgreSQL 后端；生产构建使用 `pnpm run build`，之后执行 `pnpm pwa:validate`。

## 使用边界与反馈

- 网页控制和展示不替代桌面采集。关闭网页、返回作业板或网页失联不会自动停止桌面会话；原生接管时不自动退回网页采样。
- 噪音数据是 **dBFS 信号电平**，不是校准后的声压级，不与旧网页评分混用，不用于班级排名。本版不提供原音频上传、摄像头采集或跨班批量考试控制。
- 学校排程仍依赖可靠的 ClassIsland 学校时间。需要立即停止离线设备时，必须在设备侧处理。
- ExamAware 编辑器退出协商的已知问题仍保留：切换前保存并关闭编辑器，返回日常前结束放映。
- Release 公布不等于服务器已经部署，也不等于所有学校设备已升级。未合并的设备操作概览与诊断导出不列为本版功能。
