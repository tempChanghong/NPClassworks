# 教室大屏麦克风对照诊断

在「设置 → 噪声监测」的麦克风选择区域，选择实际输入设备，点击「安静 / 说话对照诊断」。

1. 尽量在安静教室里测试，固定站位和系统麦克风音量。
2. 第一阶段保持安静约 5 秒；出现第二阶段提示后正常说话约 5 秒。
3. 记录设备名称、两个阶段的 dBFS、变化量，以及浏览器报告的音频处理状态。
4. 在相同位置重复，再换其他可用的物理输入设备对照。

阶段电平按采样 RMS 的均方能量计算。dBFS 是数字输入电平，不是 dBA 或经校准的声压级。6 dB 只用于提示本次对照差异较小，不是设备合格线，也不能据此诊断自动增益。静音、房间一直有人说话、距离、指向性和音频处理都可能影响结果。

浏览器设置来自实际音频轨道的 `getSettings()`：未报告与关闭分开显示。即使浏览器报告自动增益、降噪和回声消除关闭，也不能证明设备内部或驱动没有处理音频。测试只在内存中处理振幅，不保存录音或诊断结果。

测试期间暂停原有监测，结束后按原有生命周期恢复；离开页面会取消采样。若用户停止监测或定时监测到期，测试不能重新开启监测。

本轮没有改变评分模型：当前相对活动评分会将稳定的持续声音视作背景。因此分数不能单独证明教室安静。需要学校设备的对照结果，再决定固定安静基准或其他评分调整，避免用未经验证的默认分贝值替代这个问题。
