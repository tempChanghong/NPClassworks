# NPClassworks v1.1.5 · Ikuyo（喜多郁代）

## 版本概述

v1.1.5 是基于 v1.1.0 的课堂使用体验与可靠性更新。

本次更新围绕教师备课、学生核对与大屏抄写，新增个人作业模板、历史作业复用、必做与选做、需带物品、提交说明、发布前预览、明日与假期清单，以及文字分享。大屏布局和教师确认机制同步调整，并修复连续编辑、版本冲突、历史操作及考勤重试中的多项问题。

## 新增功能

### 教师备课与发布

- **个人作业模板**：模板跟随教师账号同步，换电脑也能使用；可保存标题、正文、选做内容、提交说明和常用需带物品。支持 `〔页码〕` 等填空项，填写并核对预览后套用，不自动发布。每个账号最多保存 50 个模板。
- **从历史作业快速复用**：选择某日的一项或多项作业，每次最多 20 项，逐项核对新日期、班级和内容后发布或保存草稿。截止时间和携带日期需要重新确认；创建新记录，保留原作业及历史。
- **发布前大屏预览**：使用实际作业卡片预览本次输入，可按目标班级切换，明确标注尚未发布。预览不保存或发布内容，返回编辑后保留输入。
- **必做与选做**：可在正文之外单独填写选做内容，添加后区分必做与选做。作业板、放大、抄写、周总览、版本历史及导出清单同步展示。
- **提交说明**：可补充“早读前交给课代表”等上交要求，与作业一起展示、同步和保存历史，也可加入个人模板。
- **本次更正原因**：修改已发布作业时可填写原因，大屏更正提示和版本历史保留本次说明，后续编辑不自动沿用旧原因。

### 学生核对与清单分享

- **需带物品清单**：作业可附带物品和独立的携带日期，大屏与学生端集中展示今日、明日及之后的准备事项。支持从更早布置的作业中提取，携带日结束后退出当前清单，原内容和历史继续保留；“今日无作业”也可附带物品。
- **明日要交与需带**：按北京时间的下一个自然日，汇总明日截止作业和需带物品，并单列今日未设置截止时间的作业供核对。支持教师选班、打印/PDF、图片及文字清单。
- **放假作业汇总**：自定义假期名称、日期和向前查找范围，汇总假期内布置或截止的作业，也可手动选择其他查到的作业。按科目整理后导出，不创建重复的发布记录。
- **查看今日更正**：主动查看当前作业板日期、所选班级的作业在今天发生的内容更正，显示改前、改后、版本和更正原因。新打开的学生页或大屏也可查询，不必曾经显示过旧版本。
- **文字版作业清单**：预览并勾选需要分享的科目，一键复制班级、日期、必做、选做、截止时间、提交说明和需带物品，便于自行粘贴到班级群。浏览器拒绝自动复制时，保留可全选的文字供手动复制。

### 大屏抄写与录入

- **抄写模式**：按项放大作业，支持手动翻页、调整字号和定时轮播；长正文分屏保留重叠行，也可滚动查看。通知弹窗或页面进入后台时暂停轮播，作业更正时停止并提示核对，退出后恢复原浏览位置。
- **大屏填写选做与物品**：录入、修改作业时可填写必做、选做、需带物品和携带日期，覆盖草稿恢复、离线保存和版本冲突处理。
- **考勤快捷入口**：底部“录入作业”旁增加“录入考勤”，直接进入今日考勤。沿用现有名单和保存流程，隐藏考勤工具时同时隐藏快捷按钮。

## 体验优化

- **通知默认显示一天**：未填写自动失效时间时，默认在发布时间的 24 小时后停止显示，表单提示与预览同步调整；手动指定的失效时间和已有通知保持原值。
- **更紧凑的大屏布局**：保留“NPClassworks 作业板”和“热爱创造奇迹。”标题与副标题，突出抄写、录入与日期操作；科目录入状态和需带物品改为可展开摘要，低频功能集中到更多菜单。
- **保留底部快捷栏**：原有入口与左、中、右位置设置继续可用，窄屏允许换行，页面按实际栏高留出空间，便于查看最后一张作业卡片。
- **长作业排版**：自动列数模式结合列宽、字号和内容长度，让较长作业跨两列；不截断正文，也不按内容量自动缩小字号。手动列数与单列模式保留原有规则。
- **简化教师确认标识**：大屏和学生端隐藏未确认标识，仅显示“教师已确认”。放大、抄写、准备事项和导出清单采用相同规则，未确认作业仍正常展示，实际确认状态不变。
- **待处理中心聚焦今日**：教师待处理列表、分类数量和顶部角标仅统计作业板日期为今日的未确认事项，跨午夜自动更新；旧作业仍可在发布记录中查看，不删除、不自动确认。
- **完整展示补充信息**：周总览、版本历史、待处理中心及各类清单补齐选做、提交说明、需带物品等信息；教师发布列表支持搜索选做内容。
- **模板替换含义明确**：套用模板时完整替换对应字段，空选填项也会清空编辑器原值；携带日期重新填写，避免旧要求混入新作业。

## Bug 修复

### 编辑、保存与版本冲突

- 修复大屏解决正文冲突时，额外写回不可编辑字段旧值的问题；保留服务器最新提交说明等未由本次操作编辑的信息。
- 修复教师保存期间继续输入后，上次更正原因进入下一版本的问题；已提交原因会清理，保存期间新填写的原因和内容继续保留。
- 修复大屏保存期间仍能继续输入、成功关闭窗口后丢失后续修改的问题；保存和冲突处理期间统一保护相关输入与操作。
- 修复连续版本冲突后读取最新版失败时，仍保留过期对比、未正确显示错误的问题；保留本机输入，并要求重新核对。
- 修复部分保存失败只显示通用 HTTP 错误的问题，优先展示服务器提供的具体业务说明。
- 完善选做、需带物品、携带日期及无作业标记的校验与清空处理，保护可恢复草稿；防止迟到的文本框回调抢走选做输入焦点。

### 历史、确认与复用

- 修复旧版本确认请求被误报成功、界面显示错误确认版本的问题，与后端版本校验配合处理冲突。
- 修复草稿及已撤回内容在历史窗口出现无效确认入口的问题。
- 历史恢复与教师确认增加操作互斥及应用刷新保护，避免重复写入、保存中关闭窗口或刷新后无法判断结果。
- 修复历史复用列表刷新后继续保留已改期或失效来源的问题；进入编辑前重新核对最新内容，防止迟到请求恢复已取消的选择。
- 复用过程中保留失败项目的输入，已成功保存的项目不因下一项重试而重复提交。

### 清单、布局与考勤

- 修复明日清单遗漏请求进行期间刚到发布时间的作业或物品的问题，在全部响应返回后判断可见性。
- 明日清单和今日更正遇到作业版本、范围、日期或可见性变化时，清除失效结果并提示刷新；避免旧响应或不完整分页结果继续用于核对、导出。
- 修复防烧屏微移使固定快捷栏离开首屏的问题，并保持滚动后的定位与微移效果。
- 修复筛选后只剩一个科目或班级时，筛选清除入口消失的问题；修复宽屏切换到单列后残留跨列样式造成的挤压。
- 修复考勤错误重试、名单变更或跨日重新载入时，可能直接丢弃尚未保存输入的问题；重新载入前确认，并隔离已变化的考勤范围。

## 性能与资源优化

- 大屏辅助区域按需展开，长作业按实际布局分配列宽，减少首屏重复信息与不必要的纵向占用。
- 清单切换日期、班级或关闭窗口时取消过时请求，释放不再需要的监听，避免旧结果继续影响当前页面。
- 抄写轮播在后台或通知弹窗期间暂停；明日清单仅在窗口打开时执行跨日检查。
- 新增浏览器性能基线与真实发布版本升级验收工具。开发电脑上的自动化数据用于后续比较，不等同于教室大屏实测，也不代表所有设备获得相同速度提升。

## 测试与发布保障

- 扩展真实 PostgreSQL、HTTP、Socket.IO 与浏览器全链路回归，覆盖账号模板隔离、并发上限与版本冲突、准备事项、选做、提交说明、历史复用及更正查询。
- 增加抄写轮播、离线首次打开、清单跨午夜失效、文字复制失败、历史写入互斥、大屏布局及考勤重试等浏览器测试。
- 增加教师确认展示和今日待处理筛选回归，包括午夜刷新失败时仍移除昨日事项、保留历史发布记录的情况。
- 补充已发布源码版本的 PWA 升级验收及手动工作流。现有固定版本验收覆盖 v1.0.1 → v1.1.0，不将其作为 v1.1.0 → v1.1.5 已完成实测的证明。
- 修正浏览器测试中的异步等待、旧文案预期和固定日期夹具，保留对实际业务行为的检查。

## 升级说明

- 建议与 **NPClassworksKV v1.1.5** 配套升级，优先更新后端以提供模板、跨日期物品查询和今日更正接口，再更新前端。
- 保留现有前端与独立 API 域名部署方式。本轮功能复用已有数据表和发布元数据，无新增数据库迁移，无需修改服务器部署代理。
- 大屏应在保存当前输入后更新应用；旧页面不会因后端更新自动获得新布局或新字段展示。不需要清除站点数据，以免丢失本机草稿、待上传作业和缓存。
- 模板保存与历史复用需要联网；抄写模式可使用已缓存作业。明日、假期和今日更正等按需查询需要联网获取结果，导出的文字、图片和纸质清单以生成时内容为准。
- “明日”指下一个自然日，不自动推断周末、节假日或下一上课日。需带事项到期隐藏，不删除历史记录。
- 未确认标识隐藏和今日待处理筛选均属于前端展示调整，不取消教师确认流程；通知已读与确认回执机制保持不变。
