# 显示缓存、组件加载与旧会话验证

## 显示缓存

`screenOfflineCache.js` 保留原有存储键和三天有效期。启动恢复大屏会话时，以及写入显示缓存时，清理过期或损坏记录；显示缓存最多保留 30 条，键和值的 UTF-16 估算总量不超过 1 MiB。超过上限优先淘汰最早保存的数据；浏览器仍报配额不足时，仅继续淘汰旧显示缓存后重试。

清理仅针对 `classworks-v2-screen-feed-cache:`，不读取或删除待上传队列、草稿及凭据的内容。单条结果超过显示缓存预算时不缓存它，在线结果照常使用；已有的有效缓存尽可能保留。存储不可用不阻断页面加载。

## 组件加载

教师编辑器、教师发布管理、教师待处理列表按角色挂载时加载；大屏录入、版本历史、通知回执和发布结果弹窗在首次打开时加载。首次挂载为打开状态的弹窗也执行初始化，保证历史/回执数据和大屏草稿正常恢复。

PWA 继续预缓存这些分块。浏览器测试验证：页面初次打开没有请求大屏录入组件，断网后首次点击录入，从 Service Worker 成功加载该分块；关闭、重新打开后草稿保持原样并可进入离线队列。

同一环境生产构建的 `index.html` 加首页路由静态 JavaScript 依赖集合：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 未压缩 JS | 759,852 字节 | 668,077 字节 |
| 各文件 gzip 合计 | 254,337 字节 | 227,852 字节 |

静态依赖未压缩体积减少约 12.1%，gzip 合计减少约 10.4%。这是构建图比较，不是低配设备启动时间实测。PWA 安装仍下载预缓存分块；本轮主要减少首屏需要解析执行的代码，不能将上述数字当作全部安装流量降幅。

## 旧会话权限验证

后端新增 `tests/sessionRevocationHttp.test.js`，使用真实 Express 路由、签发令牌、鉴权和管理服务，仅将 Prisma 数据库调用替换为可变夹具。测试复用操作前已成功访问的同一份凭据，通过管理 HTTP 接口执行撤销，再检查：

- 停用大屏后，旧令牌访问名单、列表、会话、心跳及补传接口均返回 401，未进入作业写入。
- 重置设备后 tokenHash 变化、设备指纹清空，旧令牌同样被拒绝。
- OWNER 将 ADMIN 降为 VIEWER 或移除成员后，旧 JWT 的管理读取、修改和设备重置均返回 403；OWNER 仍可正常访问。

四项测试通过，没有复现所怀疑的撤销后越权，因此未修改后端权限逻辑。此验证不覆盖真实数据库持久化、撤销瞬间已经在执行的请求，或停用后再次启用的业务策略；断网设备也无法即时获知服务器撤销。后续联网请求的拒绝已验证。

前端运行 `pnpm test`、`pnpm run lint:check`、`pnpm run build`、`pnpm test:e2e`；后端运行 `node --test tests/sessionRevocationHttp.test.js`。
