# NPClassworks v1.3.5 · Yamada（山田凉）

当前源码版本为 **v1.3.5**，代号保持 **Yamada（山田凉）**。NPClassworks 与 NPClassworksKV 源码版本一致，配套 **NPEduTools v1.1.5 · EVA-02（二号机）**。本轮为本地版本与维护检查，不代表发布、部署或生产验收。

## 当前范围

- 保留统一的 NPEP 学校自习设置，专业阈值收到高级设置；旧噪音配置作为兼容入口，不再提供另一套独立新排程。
- 保留管理员配置排程、设备与统计报告、摄像头捕获及自习座位表管理，区分请求受理与新鲜执行状态。
- 保留作业录入与实时同步、手机端布局改进及大屏刷新期间稳定布局。

## 已移除的入口

非 NPEP 浏览器噪音监测入口已关闭，无论学校是否开启 NPEP；原生监测由 NPEduTools 执行。旧实现与浏览器历史兼容代码未在本轮机械删除。

## 验证边界

本轮只使用本地构建、自动测试及隔离接口夹具。不连接生产学校，不执行数据库迁移，不使用 Docker，不修改 NPEssentials。真实数据库、学校设备、USB、摄像头与部署验收仍须分别核对；历史发布说明保留。
