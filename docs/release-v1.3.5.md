# NPClassworks v1.3.5 · Yamada（山田凉）

v1.3.5 整理学校自习管理入口与高级参数，改善手机和大屏的操作反馈。代号保持 **Yamada（山田凉）**，配套 **NPClassworksKV v1.3.5** 与 **NPEduTools v1.1.5 · EVA-02（二号机）**。

## 改进与修复

- **统一 NPEP 自习管理入口**：设置、执行状态、报告与照片在同一工作区内切换，旧噪音排程只作为兼容路径，避免管理员为同一安排维护两套设置。
- **常用设置优先**：双阈值、连续超限时间和提醒间隔收到默认收起的高级设置；未修改考试模式的只读查看不产生未保存草稿，验证失败定位对应设置区。
- **手机布局**：修复自习设置右半边横向裁切，模式、时间和日期输入随窄屏排列，长作业来源名称不撑宽页面。
- **作业板更稳定**：保留当前作业布局直到新数据到达，减少录入后的刷新抖动；保存、同步与等待刷新分别反馈。
- **自习默认值**：新安排默认北京时间 **19:15–21:30**，估算声压级新策略默认双阈值 **50／65**；不覆盖已有自定义时段或阈值。临时使用电脑按连续无操作时长返回，默认十分钟，与原生端策略一致。
- **诊断可追踪**：学校诊断导出保留 `v1.1.5 · EVA-02（二号机）` 对应的规范版本与可选提交标识，继续排除任意附加文本。

## 移除功能

延续 v1.3.0 的退役规则：**非 NPEP 浏览器噪音检测入口关闭，无论学校是否开启 NPEP**。网页不再开始浏览器手动／本机定时采集，也不因原生设备离线自动退回浏览器麦克风。采集与全屏自习展示由 NPEduTools 执行。

旧浏览器历史兼容代码和既有本机记录保留；入口停用不清空站点数据，不将旧评分转换为原生统计。已有作业板、教学管理与通知功能继续使用。

## 升级与使用

1. 先备份并更新 KV v1.3.5，应用完整迁移链、核对健康状态，再更新网页及 NPEduTools v1.1.5。
2. 只配置过旧噪音时段、尚未建立新自习设置的范围由 KV 兼容迁移；已有新策略与明确自定义安排保留，不自动启用考试安排或照片。
3. 保存作业和管理草稿后刷新／重开 PWA，通常无需清空站点数据。核对班级、日期／星期、两种模式、学校口令和默认设备。
4. 配置保存、请求受理、设备应用和实际采集仍是不同事实，以新鲜执行回执判断状态。照片只在授权的学校管理后台查看，保留期限与备份边界仍由部署方说明。

## 验证与发布边界

网页单元、lint、构建、浏览器与三仓组合 CI 通过；可选 Claude 审查按配置跳过，不计作测试通过。真实设备、USB、触控和声学验收不由自动测试替代，联机校准仍为 Beta。dBFS 与估算 dB(A) 分开显示，不用于班级评分或排名。

本 Release 提供前端源码及可离线保存的说明，不是桌面安装包；GitHub 发布完成不代表每个学校已完成部署或设备升级。公开附件不包含学校配置、密钥、学生资料或数据库备份。
