# 无作业标记与一周总览

## 教师明确标记无作业

在教师的“新建发布”或“编辑发布”中选择科目、发布目标和作业板日期，开启“该科目在所选日期无作业”，然后正式发布。标记沿用普通作业的授课范围、草稿、定时发布、修改、撤回、教师确认和历史记录流程。

开启开关会填入固定标题“今日无作业”和正文“本日该科目无作业。”，清空截止时间；提交前关闭开关可恢复原先输入。修改已经发布的标记时，关闭开关后填写新的作业正文即可转为普通作业。

学生页与大屏的“各科录入状态”按作业板日期、科目和具体教学班区分尚未录入、已有作业、明确无作业。同一天、同科目、同教学班同时存在普通作业与标记时，显示冲突提示并继续展示全部作业。未获教师确认的标记会显示待确认状态；离线时注明依据缓存判断。状态依据当前已加载的公开内容，不能代表尚未发布的教师草稿。

无作业标记不计入本机作业完成进度，也没有“标记完成”按钮。

## 一周总览

- 学生“看作业”页：班级选择摘要旁的“一周总览”。教师也可切换到“看作业”使用。
- 大屏：“更多 → 一周总览”。
- 默认打开当前作业板日期所在周，以周一至周日为一周，支持前后周、本周、科目筛选和手动刷新。
- “按作业板日期”：显示这七天的已发布作业及无作业标记。
- “按截止日期”：按北京时间归类，包含在更早日期布置、但在这一周截止的作业；不包含没有截止时间的作业和无作业标记。
- 同一条多目标作业在总览中只展示一次，展示其与当前所选范围相交的目标。
- 总览读取当前发布状态，未到发布时间、草稿、已撤回作业与通知不计入；不重建过去某一时刻的发布状态。
- 周数据逐页加载，全部完成后展示。切换日期、方式或班级、关闭弹窗会取消旧查询。一周总览目前需要联网，加载失败时显示错误，不能将失败视为空清单。

## 兼容与部署

无作业标记沿用 Publication 的现有 `contentJson` 字段：`{kind: "NO_HOMEWORK", version: 1}`，并同时保存可读的普通标题和正文。旧版客户端可看到文字；若旧版修改了正文、标题或设置了截止时间，新版会将它视为普通作业，避免元数据残留造成误判。

一周总览扩展现有公开和大屏 feed 接口，增加 `weekStart=YYYY-MM-DD` 与 `weekView=board|due`，保留现有日查询和权限验证。需要配套更新后端。旧后端未返回周查询信息时，新前端会提示后端尚不支持，而不会把日查询结果当成整周数据。

本次不涉及数据库结构迁移，不修改部署代理或服务器配置。
