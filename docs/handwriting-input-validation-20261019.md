## 识别与资源开销

16 组固定生成字样（含中文数字、0/O、1/l、范围和化学式），每组重新绘制并识别三次：48 请求、54 行真实推理，与隔离 round25 r19 的原始及语境修正输出均无变化，没有用行结果缓存代替推理。

本开发机 Edge 这一轮的操作计时包含自动化开销：端到端中位数 **234 ms**，P95 **340 ms**，最大 **882 ms**（含首次资源准备）；去掉首次冷启动后，模型阶段按请求合计中位数 **96.8 ms**、P95 **149 ms**。RAF 观测最大间隔 12.2 ms。这不是学校一体机的速度或触控承诺。

页面 JS 堆中位数 **16.45 MiB**。在每次请求结束、模型会话仍存活时，整个独立浏览器进程组 PrivateBytes 中位数 **697.20 MiB**、P95 **789.36 MiB**；同一浏览器打开手写前为 655.32 MiB、关闭后为 597.75 MiB。后两项包含完整 NPClassworks、浏览器、渲染器及其他已结束测试上下文的回收波动，不能据此宣称 OCR 单独占用约 697 MiB、净增固定数值或已证明内存降低；这些采样也不等于原生调用瞬时峰值。没有强制 GC。

持续识别时始终只有一个推理 Worker；资源 Worker 已退出。确认关闭后，既检查终止调用，也用 CDP 确认专用 Worker target 归零。输入缓冲上限沿用 r19 的三块、总容量 2,654,208 字节。

从 `e5e689d0c51555309f2565c3d5a0f86686bff558` 干净工作区继续；修复提交 `1bbe5e52706f32a63c10b4f15bc22ef1783a935f`。先用生产构建复现，再修改：
