# NPClassworks UI.1：首轮优化交付记录

日期：2026-10-03。对应 [UI 综合评审](../../docs/NPCLASSWORKS-UI-DESIGN-REVIEW.md) 的 UI.1 任务卡。本轮在当前本地工作区实施，尚未提交、推送或部署。

## 目标与实现

**目标：学生在手机上更早看到作业，同时能找到选班、日期、需带物品、科目状态和原有工具；三端共享清楚的浅深主题。**

- 手机页头改为紧凑班级摘要，保留明日核对入口；周览、假期、更正、打印、复制、修改选班和刷新收进“更多”。从菜单打开对话框时，先完成菜单关闭，避免两个浮层争夺焦点。
- 手机日期条使用紧凑布局，任意日期仍可选择。筛选和完成统计合在可展开的一行；单条作业不再重复显示一次科目分组标题，默认“普通”优先级不再重复强调。
- “需带物品”仍在作业前；如果某科尚未录入或发生冲突，前部出现简短提醒。完整科目状态留在作业之后，可按需展开。“无作业”和“尚未录入”的业务含义未合并。
- 390px 及更窄的导航保留“看作业／教师／大屏”文字。选班摘要依据已加载的课程规则简短显示“全科随行政班”；无法确认时提示到“更多”核对走班。
- Vuetify 浅深主题采用现有暖橙品牌的中性色搭配。深色主按钮用浅橙底／深字，浅色用深橙底／白字；两组纯色对比度分别约 9.76:1 和 5.52:1。状态色仍由各自语义管理。

本轮没有修改接口、权限、发布、更正、同步、NPEP 设备控制或教师工作台的信息结构。

## 验证

- 当前源码完成生产构建与改动文件 ESLint 检查。
- [新增端到端回归](../../tests/e2e/student-ui.spec.js) 3 项通过：手机入口、菜单／打印／筛选／完成状态、尚未录入提示、320px 重排，以及大屏浅深主题主按钮的实际文字对比度。
- 原有选班、打印、大屏布局端到端测试 **15 项通过**。
- 23 个隔离浏览器捕获状态均未出现未捕获页面异常；本次所列主页面没有整页横向溢出。

手机使用的是 Chromium 触摸视口模拟，截图不能代表 Android／iOS 真机、中文输入法或课堂一体机。UI.2 的教师任务布局、UI.3 的后排阅读与旧设备持续运行仍需按综合评审分别实施和验收。
