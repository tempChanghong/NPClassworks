# NPEP N1 学校管理界面与验收

日期：2026-09-21。前端分支：`codex/npep-n1-admin-ui`。后端配套基线：`codex/npep-n1-server` / `e03ff22`。

本轮为 N1 增加学校管理网页入口，不修改生产配置、不部署、不更新 v1.1.5 release 文档或版本号。NPEduTools 正式设置页和 Host 生命周期由对应项目任务实现；这里仅负责 NPClassworks 学校管理界面。

## 入口与交互

学校 OWNER / ADMIN 登录后，在 **学校管理 → 大屏设备 → 打开 NPEP 设备互联** 中操作。组件延迟加载，关闭或离开页面后销毁；未打开面板时不发 NPEP 请求，旧服务器不会因新增入口产生自动失败请求。

1. 在 NPEduTools 发起申请，输入其 8 位短码（支持显示横线、小写输入规范化）。
2. 网页显示申请设备名、版本、期限，选择本校有效大屏与行政班；明确勾选核对结果后才能批准。
3. 批准只记录批准结果，仍须 NPEduTools 现场核对并确认。网页不持有 pairingSecret 或 deviceSecret。
4. 刷新登记列表，查看设备、绑定、授权期限、最近观测时间，以及模式、录制、自动录制启用状态和桥接状态。20 条分页，可继续加载。
5. 撤销前单独确认设备与班级；成功后立即更新本地授权状态并重新读取列表。撤销互联不等于重置网页 PIN/大屏 token。

设备列表采用显式刷新，不进行后台轮询。“在线”表示查询时收到的新鲜上报；缓存观测超过 60 秒后显示“观测已过时，请刷新”，不会仅凭未刷新网页认定设备已经离线。服务端明确返回 OFFLINE 时显示失联；模式始终标为上次观测。自动录制“已启用”与“正在录制”分开显示。历史设备绑定与现有班级不一致时明确显示原班级绑定已变化。

## 请求与状态保护

- 复用现有管理员账号会话及令牌续期，仍由后端复核有效可撤销会话和学校角色；没有浏览器设备凭据兼容路径。
- 每个请求带 v0.1 版本与 UUID 请求 ID；续期重试沿用原 ID，审批响应丢失后手动重试也沿用同申请/绑定的 ID。
- 核验响应协议版本、请求 ID、服务器时间；拒绝不匹配信封。
- 学校切换、关闭面板和卸载使旧请求失效；切换账号后的旧成功响应由 API 层拒绝。
- 网络失败保留列表并标注过时，禁用基于旧列表的撤销；401/403 清除设备和申请资料。服务未启用、过期、占用、撤销冲突、限流等显示对应中文提示。
- 短码只存在当前组件内存，不写入 localStorage、诊断或 URL。页面只调用管理接口与 info，不调用设备身份接口，不增加通知/模式权限。

- `pnpm lint:check`：通过。

- `pnpm exec playwright test tests/e2e/admin-screens.spec.js`：17/17 通过，覆盖原学校管理交互及新增批准重试、分页、刷新失败、撤销确认、窄屏关闭后迟到响应。
- 真实前端生产构建 + Express N1 API + 隔离 PostgreSQL：`tests/fullstack/npep.spec.js` 通过。真实网页解析/批准之后数据库尚无设备；设备确认及上报后网页显示在线；网页撤销后数据库 REVOKED，旧 bearer 返回 401。
- 已检查真实网页截图，长内容允许换行，配对与设备观测分栏展示，小屏改为纵向排列。

真实 N1 全链路需显式设置 `FULLSTACK_NPEP=true`，再运行：

```powershell
$env:FULLSTACK_NPEP = 'true'
node scripts/run-fullstack.js tests/fullstack/npep.spec.js
```

如默认端口被占用，可分别配置 `E2E_WEB_PORT`、`E2E_API_PORT` 和 `FULLSTACK_POSTGRES_PORT`。脚本只接受 localhost 的 `npclassworks_test_fullstack*` 库，创建本次专用配置代际；默认不打开 NPEP。由于配套后端尚在独立分支，现有 CI 未显式开启此新增全链路场景；双方集成后应把该场景纳入部署门槛，不能将默认跳过说成已在 CI 验收。

另已按设备端任务请求重新开放原 `https://localhost:34439` 隔离服务供 NPEduTools Runtime 联调。对端报告真实 Runtime 验收 17/17 通过，涵盖现场确认前不报告、确认后常驻报告、暂停跨重启、恢复新会话、撤销与本机清理；这些数字来自对端验收，本任务没有将其视为双端正式界面的现场验收。临时管理员凭据、证书、虚构学校绑定保存在后端 ignored 的 `deploy/runtime/npep-n1/`，不纳入本提交。联调后仅停止该 HTTPS 进程，保留数据库与夹具。
