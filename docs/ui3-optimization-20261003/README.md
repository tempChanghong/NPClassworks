# UI.3 班级大屏展示与操作优化

日期：2026-10-03。范围：NPClassworks 已绑定班级大屏的常态看板、阅读设置、快速录入和底部操作区。与 [UI 综合评审](../NPCLASSWORKS-UI-DESIGN-REVIEW.md)第 7、13 节使用同一组本地合成数据：六科作业，其中有长作业、选做、提交说明、需带物品和未确认状态。

## 完成的调整

1. 已绑定大屏只显示班级专用页头，不再叠加通用应用导航。移除页头与底栏重复的“录入作业”及作业区前重复的更新时间／教学空间数量；保留同步状态、日期、科目状态、需带物品、筛选和固定录入入口。
2. 新设备默认使用 160% 正文字号，隐藏作者与发布时间等次要元信息。设置页提供近距操作 120%、普通教室 160%、后排阅读 200% 三种预设和实际文字预览，仍可用滑杆细调。已有设备保存的设置继续生效；如需常显来源和发布时间，可在显示设置中重新开启。
3. 科目、正文、提交说明和需带信息一起放大；截止时间和状态标签保持可辨。自动列数按字号与可用宽度计算，长作业在本列向下展开，避免自动跨列造成的空位和视觉顺序变化。正文不截断，原有“放大查看”和抄写模式继续可用。
4. 1280px 与 1366px 宽度的底部栏保持单排，保留大尺寸触控按钮；滚动到底时最后一张卡片能完整露出。默认高效模式取消底栏背景模糊，并用不透明底色隔开底下的文字。
5. 大屏快速录入分区改用文字标题，避免“1”直接跳到“3”的步骤编号。保存、取消及选做／提交／需带输入逻辑保持原样。
6. 根据 1920 × 1080 截图反馈，收小页头班级名和“即将截止”标签。普通教室预设下分别约为 21.84px 与 17.41px，正文保持 28.16px；更窄的 1280px 视口下班级名约为 20.56px。

## 同场景对比

坐标为 CSS 像素，均由 Windows 无头 Chromium 在固定日期、相同六科夹具和 100% 浏览器缩放下测得。原值来自 [评审基线](../NPCLASSWORKS-UI-DESIGN-REVIEW.md)；本次原始记录在 [measurements.json](measurements.json)。这些数字描述页面布局，不等于物理观看距离下的清晰度。

| CSS 视口 | 首张卡片顶端：改前 → 改后 | 默认作业正文：改前 → 改后 | 自动列数 |
| --- | ---: | ---: | ---: |
| 1920 × 1080 | 355 → 213 | 20.8 → 28.16px | 3 |
| 1366 × 768 | 约 354 → 212 | 20.8 → 28.16px | 2 |
| 1280 × 720 | 368 → 226 | 20.8 → 28.16px | 2 |
| 3840 × 2160 | 基线未记录顶端位置 → 246 | 20.8 → 28.16px | 5 |

在 1920 × 1080 下，近距预设的正文为 21.12px，后排预设为 35.2px，后者自动减少到两列。1280 × 720 的底栏从两排约 134px 降为单排约 74px。所测视口均无横向溢出，也未出现页面脚本错误。源码中的右下底栏留白与浏览器回归一起验证了滚动到底时末张卡片位于底栏之上。

## 验证与边界

本地生产构建通过；受影响文件 ESLint 无警告；屏幕设置单元测试 4 项通过；浏览器回归 22 项通过。回归覆盖了长文显示、不同宽度的重排、底栏与最终内容避让、浅深主题主按钮文字对比、抄写、快速录入保存边界、阅读预设的本机持久化。浏览器回归只使用回环地址与内存 API，没有部署。

仍需在实际教室检查：后排能否辨认科目／正文／截止与异常；不同 Windows 缩放和一体机尺寸；真实触摸驱动下录入、保存、取消、日期切换的命中；旧设备持续运行一个教学时段时的 CPU、内存与掉帧。无头浏览器截图和高效模式的样式读回，不能代替上述验收。
