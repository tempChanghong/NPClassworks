# 全校作业快捷设置拆分

本轮只拆分学校管理页中的快捷词和快捷截止时间，保留接口、校验、提示、默认值及原有加载时机。

## 职责与生命周期

- `useSchoolHomeworkSettings.js`：保存两类配置、学科列表、保存快照和忙碌状态，负责原有加载、编辑辅助、校验和保存操作。
- `AdminHomeworkQuickInputs.vue`：教师分配标签页内的快捷词表单。
- `AdminHomeworkQuickDeadlines.vue`：大屏设备标签页内的快捷截止时间表单，包含原有窄屏样式。
- `classworks-admin.vue`：保留学校/学期与标签页选择、权限判断、共享消息、加载触发和未保存离开判断。

父页面 setup 只创建一个设置管理对象，两个子组件使用其中相同的 refs。不能在子组件中分别创建管理对象或在页面生命周期内替换传入对象，否则两类配置可能相互覆盖。标签页延迟挂载不会重建配置或保存快照。

两个“保存全校配置”按钮仍调用同一个方法，同时提交 `quickDeadlines` 与 `quickInputs`。空快捷词数组仍表示关闭快捷输入；恢复默认只修改草稿，保存成功后才更新快照。未修改任何 watcher 的触发条件或原有未保存判断范围。
