# NPClassworks v1.3.0 · Yamada（山田凉）

## 版本概述

**v1.3.0，代号 Yamada（山田凉）**，是基于 v1.2.5 的 NPEP 自习管理更新。配套 **NPClassworksKV v1.3.0** 与 **NPEduTools v1.1.0 · EVA-02（二号机）**。

学校后台统一管理自习安排、作业来源、自习座位表、设备与报告；全屏自习展示和实际采集转由 NPEduTools 承担。网页继续提供作业板、教学管理、通知和考试操作，本版不重新推出这些既有功能。

## 新增功能

### NPEP 成为独立管理分组

- 左侧 **NPEP** 与“日常管理”“学校配置”等同级，集中放置大屏互联、噪音／自习监测及相关管理入口，减少在大屏设备页面反复展开查找。
- **自习设置**统一管理时段、展示、作业、阈值和拍照策略；**噪音监测**集中查看执行状态、报告与照片。旧排程编辑器收进默认折叠的兼容区，切页或收起时保留未保存草稿。
- 设备概览、远程操作、诊断与执行回执集中展示，分别说明“保存配置”“请求受理”“设备应用”和“实际采集”。陈旧、离线或失败状态不冒充正在监测。
- 沿用学校现有管理账号与后端授权范围；本版不新增独立的逐账号 NPEP 权限编辑器。

### 自习安排、作业和自习座位表

- 后台按学期、年级和班级配置继承、覆盖或关闭，支持星期、生效／结束日期与日历例外；**日常模式和考试模式独立设置时段**，允许某个模式没有安排。
- 新配置默认 **北京时间 19:00–21:30**，保留用户明确自定义的排程。适用学校、班级、星期及日期仍需管理员填写，不硬编码某所学校的三晚开始日期。
- 配置自习展示的噪音显示方式、临时收起时间、双阈值、连续超限时间及提醒间隔。高阈值连续时长默认 **3 秒**，“注意纪律”默认 **10 分钟**内至多一次。
- 选择今日作业的来源行政班，结合授课规则展示其适用走班作业，去重并隐藏无作业科目。轮换默认 **60 秒**，支持后台调整，原生端按内容分页并延后应用阅读中的更新。
- 后台上传、替换、撤回 **自习座位表**，查看版本及来源。已绑定大屏也可上传本班图片，后台标明设备来源；双方并发修改返回冲突，不用旧预览覆盖新的座位表。
- 界面说明定时展示提前 **5 分钟**打开座位表、开始前 **2 分钟**播放 **10 秒**准备提示、开始后 **2 分钟**返回原页面。座位表不加入作业轮换。

### 学校口令与远程设备管理

- 班级开启 NPEP 时配置学校管理口令；支持管理员批准设备申请，以及先预授权、再由大屏使用学校服务地址和口令连接。预授权不等于设备已经连接或开始执行。
- NPEP 接管后的管理验证使用学校班级口令，旧本机管理口令不作为回退；保存口令、修改口令和设备收到新策略仍分别显示结果。
- 查看设备上报的麦克风、摄像头列表，远程设置并锁定默认输入设备。大屏通过管理验证解除锁定后保持解锁，直到管理员再次锁定；列表或状态过时则提示刷新核对。

### 一页查看自习报告、照片与记录

- 按班级与会话查看时段、趋势、平均值／峰值、采集覆盖率、双阈值超限与提醒次数，并在同一详情中查看有权限的照片、退出验证和异常恢复记录。
- 区分手动与学校定时会话，标注日常 **ClassIsland 学校时间**、考试模式 **Windows 时间**及报告的时间异常；旧报告没有可靠归属时保留设备历史入口，不猜测归入新班级。
- 数据单位明确显示 **dBFS** 或 **估算 dB(A)**，参考校准显示来源与有效性，DLY-2202 联机参考保留 **Beta** 标识。不将旧网页评分、数字电平与估算声压级混为同一种统计。
- 学校独立启用单张照片策略：默认最小间隔 **30 秒**、保留 **30 天**，最长 **180 天**；延长保留需确认风险。仅同校 **OWNER 与第二管理员**可查看照片，不提供公开图片链接；普通自习结束报告不向全班显示照片。
- 展示捕获、待上传、已存储、失败或过期的真实结果，不能仅凭退出事件或请求受理就声称服务器已经收到照片。

## 移除功能

- **移除非 NPEP 的网页噪音检测使用入口**，关闭浏览器手动采集、本机定时采集及旧网页定时监测展示入口。无论学校是否启用 NPEP，网页都不再提供新的浏览器噪音采集。
- 原生设备离线、失联或不支持新协议时，网页提示实际状态，**不会自动退回浏览器麦克风采集**。需要继续监测时使用 NPEduTools，不把刷新 PWA 当成原生采集恢复。
- 保留旧浏览器本机历史的查看与既有数据，不因本次入口停用自动清空站点数据；旧记录不转换为原生报告，也不与新统计混合。
- 这是采集入口和运行路径的退役，不表示旧噪音模块已经全部从仓库删除，也不影响原生监测的后台控制与报告。

## Bug 修复与体验优化

- 修复座位表切班失败后旧预览可能作用于新班级的问题，提交前再次核对确认过的作用范围及修订。
- 修复陈旧电平与监测状态、结束尾段显示、时钟变化标注，以及保存配置与桌面执行反馈混淆；设备状态恢复时保留尚未解决的操作错误。
- 恢复学生手机端空状态的可读布局，改善 NPEP 设置与设备恢复反馈；统一关于页和诊断的版本元数据为 **1.3.0 / Yamada（山田凉）**。
- 修复手机自习设置的横向裁切：模式切换在窄屏纵向排列，时间输入与报告日期筛选随屏幕宽度调整，长作业来源名称不再撑宽设置区。

## 升级说明

1. 备份数据库、学校服务配置和 NPEP 身份，先更新 **KV v1.3.0**、应用完整 Prisma 迁移链并核对 `/ready`，再更新网页及 **NPEduTools v1.1.0**。保留既有绑定、身份和自定义安排。
   KV 启动前自动迁移“旧噪音排程已配置、新自习设置尚未配置”的范围；保留自定义时段和继承／关闭关系，已有新策略不覆盖。迁移不会自行安排考试模式或开启摄像头，也不清除旧数据。
2. 保存未提交的作业或管理草稿后刷新／重开 PWA；通常不需清空站点数据，以免丢失旧浏览器历史、草稿及大屏绑定。
3. 核对班级管理口令、两种模式的时段、设备能力及锁定状态。已预授权的班级仍可预先配置自习，但设备收到配置且实际开始采集须以新鲜回执为准。
4. 启用照片前告知学校使用人员，核对摄像头、查看账号、保留期限、补传与清理。服务器当前数据清理不承诺清除所有备份副本，备份期限由部署方另行说明。
5. 原来的网页独立噪音采集不再可用；学校未启用 NPEP 时仍可使用作业板等功能，监测需求另行准备桌面端。日常与考试时间来源不同，应分别验收。

- 已合并 PR [#11](https://github.com/tempChanghong/NPClassworks/pull/11) 的必要 CI 通过，涵盖单元、lint、构建、浏览器及三仓契约／全栈检查；可选 Claude 审查按原配置跳过。
- 本地网页单元 **697 项通过、14 项跳过**，完整浏览器 **183 项通过**，ESLint 通过；隔离原生 PostgreSQL 的真实网页／KV 配对全栈验证通过。跳过不计为通过。
- 真实课堂大屏、触摸、摄像头、DLY-2202 USB、声学校准及长期运行仍待现场验收；联机校准保留 Beta。关闭网页不会自动停止原生采集，发布草稿不代表所有设备已升级或生产部署完成。
- 不上传原音频，不提供视频片段捕获，不按噪音数据给班级评分或排名。新增照片按学校策略传往学校 KV，不向星火动力云端上传捕获画面。
