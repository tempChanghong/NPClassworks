# 大屏设备管理拆分

本轮仅整理学校管理页的设备账号功能，没有修改后端接口、权限规则、数据库或部署脚本。

## 模块边界

- `src/pages/classworks-admin.vue`：保留管理员登录、学校/学期选择、权限提示、全校作业设置、共享消息和撤销提示、离开页面确认，以及原有数据加载触发顺序。
- `src/composables/admin/useScreenAccountManager.js`：保存设备列表、筛选、创建及编辑草稿；执行创建、编辑、重置绑定、启停、撤销和远程指令；管理 30 秒轮询的启动、停止及卸载清理。
- `src/components/admin/AdminScreenAccountPanel.vue`：显示账号表单、设备列表、桌面按钮、窄屏菜单及编辑弹窗，并拥有对应的局部样式。

管理对象在父页面 setup 中创建一次，内部 refs 不随标签页内容的延迟挂载重新初始化。子组件接收这一固定对象，表单与父页面的未保存判断使用相同的 refs。后续维护不要在页面生命周期内替换该对象。

学校选择变化仍由父页面触发设备加载；切入设备页仍依次加载名册、设备、学校作业设置并启动轮询；切出停止轮询。轮询没有改成立即 watcher，也没有改变原有首次打开行为。

创建、编辑、重置、启停、撤销及远程指令函数按原内容迁移。空 PIN 仍不提交；失败仍保留草稿及编辑弹窗；危险操作仍需确认；撤销仍使用操作时的学校 ID。原有请求竞争和并发策略不在本轮修改范围内。

## 回归检查

`tests/screenAccountManagerFlows.test.js` 使用真实 Vue 生命周期、API 客户端和本机 HTTP fixture，覆盖失败保留输入、请求载荷、空 PIN、403、取消危险操作、命令类型、撤销学校范围、实例隔离及轮询清理。

`tests/e2e/admin-screens.spec.js` 使用生产构建和 Chromium，检查 1440px/540px 布局、编辑和创建按钮、离开确认、筛选及非管理员入口隐藏。管理 API 使用测试夹具；这项浏览器检查不能代替后端权限验证，也不覆盖生产数据库。

新增测试沿用现有普通测试及浏览器测试入口，自动随前端检查执行。

2026-09-07 本地验证：305 项普通测试通过（含 5 项新增设备管理流程测试）；3 项新增 Chromium 浏览器测试通过；全量 Lint、生产构建、PWA 产物校验及 git diff --check 通过。迁移前后的设备操作函数经逐段比对，除缩进外内容一致。

浏览器测试编写时修正了夹具对权限请求查询参数的匹配、Vuetify 下拉框定位及搜索框/清除按钮同名匹配，没有据此改变业务逻辑。本轮未执行全部浏览器测试或真实后端数据库测试；未推送或部署。
