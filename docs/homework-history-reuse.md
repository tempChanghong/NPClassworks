# 从历史作业快速复用

入口：教师工作台 → 发布管理 → **复用历史作业**。

1. 选择历史作业日期，勾选一项或多项作业（每次最多 20 项），设置新作业板日期。
2. 点击“核对所选作业”。系统重新读取所选记录的最新内容，读取失败时保留选择，不创建新记录。
3. 逐项选择有发布权限的班级，检查必做内容、选做内容、提交说明和需带物品。可以继续修改内容，并预览大屏效果。
4. 旧截止时间和携带日期不会沿用。重新填写后勾选日期确认；截止时间可以留空，有需带物品时必须填写携带日期。更改日期、发布时间或物品后需要再次确认。
5. 点击“正式发布”或“保存草稿”，成功后点击“核对下一项”。每项独立保存，不会自动发布剩余项目。也可确认跳过某项。

可选择已发布和已撤回的作业；通知、草稿及尚未到发布时间的定时作业不在本入口中。以当前账号能访问的历史记录和可发布的科目、班级为准。“今日无作业”标记也能复用，发布前仍需核对日期和班级。

复用创建全新的记录，不修改原作业及其历史，也不沿用原作者、确认状态、修订号和更正原因。新记录由当前教师通过现有发布流程创建。正在主编辑器中填写的内容不会被复用窗口覆盖。

读取和保存需要联网。失败时当前输入保留，已成功保存的项目不会在下一项重试时再次提交。尚未保存的整批复用内容不持久化；刷新会受到未保存保护，关闭复用窗口会提示丢弃剩余内容。账号会话变化时清空复用内容，迟到的旧读取结果不会恢复窗口。

## 实现与验证

复用现有发布、草稿、重复作业提醒及权限校验接口，不新增后端接口或数据库字段。

- `tests/homeworkReuse.test.js`：字段复制、日期重填、源记录隔离、候选范围、无作业语义。
- `tests/fullstack/homework-reuse.spec.js`：真实 PostgreSQL 与浏览器下的跨班级批量复用、部分失败重试、保存期间锁定、源记录不变、最新内容读取、取消与迟到响应保护。

定向验证：`node --test tests/homeworkReuse.test.js` 和 `pnpm test:e2e:fullstack homework-reuse.spec.js`。
