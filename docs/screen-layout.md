# 大屏布局调整

正式大屏采用紧凑的顶部区域和可展开的辅助信息，继续使用现有 Vuetify 主题、字号和密度设置。

- 大屏保留顶部“NPClassworks 作业板”标题和“热爱创造奇迹。”副标题；角色导航及设置入口仍按原有访问条件显示。
- 顶部突出抄写模式、录入作业和更多菜单。明日要交与需带、放假作业汇总、今日更正移入更多，与一周总览及复制/打印入口集中展示。
- 日期选择、复制到今天仍可直接操作。科目录入状态、需带物品改为可展开摘要；缓存提示、待确认信息、无作业标记和冲突说明仍可查看。
- 作业筛选和排序在大屏默认收起，启用筛选时摘要会明确提示。学生页面的筛选方式不变。
- 作业撤回或刷新后即使只剩一个科目或班级，只要筛选或自定义排序仍生效，就保留控制栏与清除入口，避免条件隐藏后无法重置。
- 通知继续使用现有折叠状态和新版本强制展开机制；收起后保留第一条通知的标题或正文摘要。弹窗、提示音及回执流程不变。
- 自动列数模式根据普通列宽、实际字体和必做/选做/提交说明/需带物品的文本测量估计行数，长作业可跨两列。手动列数和单列不自动跨列；原排序继续生效，不按文本长度重新排序。
- 从宽屏缩为单列时清除跨列样式，按配置的列数判断，避免残留的隐式列挤窄其他卡片。
- 作业正文不截断、不因内容数量增加而缩小字号，保留单科放大和抄写模式。选做与提交说明跟随大屏字号。
- 底部快捷栏保留全部原入口及左/中/右位置设置。窄屏允许换行，页面末尾根据实际栏高留出空间，滚到底后可阅读最后一张卡片。
- 防烧屏微移使用相对偏移，并单独微移快捷栏表面，避免整体变换把固定快捷栏绑定到长页面底部。浏览器验证覆盖开启后首屏可见、滚动定位和五分钟后的实际微移。

这些调整只涉及前端，无后端接口或数据库变更。`docs/prototypes/screen-layout.html` 保留为设计原型，真实页面仍以已有业务状态和用户设置为准。

浏览器回归覆盖摘要展开、长作业完整显示和放大、底栏入口及位置、日期切换、三种窗口宽度和手动列数；原有通知、离线、抄写、打印等测试继续执行。真实教室后排的可读性仍需在大屏上验收。

## 本地验证

- `pnpm test`：505 项通过。
- 完整浏览器回归运行 142 项用例，旧入口及折叠摘要相关断言适配后完成专项复测。最终排版检查验证 1920、1366、540 宽度下每张卡片宽度正常、互不重叠、底栏不遮挡页面末尾，以及宽窄屏来回切换。
- 12 项隔离 PostgreSQL 全链路测试通过，覆盖发布、通知确认、更正、明日与放假清单及导出；临时数据库已清理。
- `pnpm lint:check`、`pnpm build:store`（含 PWA 校验）通过。

后续缺陷修复复测：先分别复现防烧屏微移导致快捷栏离开首屏、单科目更新导致筛选清除入口消失，再修复。505 项单测、28 项浏览器专项回归（布局、抄写、通知、总览、学生选班）、Lint 和生产 PWA 构建均通过。本轮未重复执行数据库全链路测试。
