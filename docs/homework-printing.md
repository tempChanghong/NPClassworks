# 作业清单打印

## 使用方式

- “看作业”页面：选择行政班、走班课程和作业板日期，点击班级信息旁的“打印作业清单”。
- 班级大屏：选择作业板日期，在顶部“更多”菜单中选择“打印作业清单”。
- 确认预览后点击“打印 / 保存 PDF”。纸张默认采用 A4 排版；需要 PDF 时，在浏览器或系统打印窗口中选择对应目的地。

清单包含班级、所选课程范围、日期、科目、适用教学班、标题、完整正文、截止时间、优先级和教师确认状态。正文保留换行，长作业自然跨页，每项提供纸面勾选框。

## 内容范围

- 使用当前班级选择和日期下已经加载的已发布作业，不额外请求其他班级或后台管理数据。
- 清单打印该选择范围的已加载作业，不受页面里的科目筛选、排序或“隐藏已完成”开关影响。
- 不包含通知、草稿、撤回内容、未来尚未发布内容或本机未上传队列。同一作业命中多个所选教学班时只列一次，并只显示所选范围内的目标名称。
- 加载中、未选择班级、尚无成功加载结果，或加载失败且没有缓存时，打印入口不可用。成功加载的空日期可生成明确的空清单。
- 大屏使用缓存时，在纸面上标注“离线缓存内容，可能不是最新作业”；队列有待处理项或读取异常时也标明未上传内容可能缺失。
- 预览固定为打开时的内容，标注数据更新时间与生成时间。切换日期、选班或模式会丢弃原预览；需要最新修改时关闭后重新打开。

## 实现与验证

仅修改前端，无新依赖、后端接口或数据库迁移。打印使用独立的白底黑字文档，不改变大屏本身的颜色和布局，也不上传清单到外部服务。所有作业文本转义后输出；预览 iframe 禁止脚本，并通过 CSP 禁止外部资源加载。

单元测试覆盖日期、班级、发布状态过滤，重复项、文本转义、长正文、缓存提示和预览快照。浏览器测试覆盖学生入口、大屏菜单、离线缓存、空日期与日期切换、打印按钮调用和 Chromium PDF 跨页输出。系统打印窗口的选择与纸张输出由用户完成，测试不向实体打印机发送任务。

```sh
node --test tests/homeworkPrint.test.js

```
