# 抄写模式与个人作业模板

## 大屏抄写模式

入口：大屏顶部“更多 → 抄写模式”。显示当前日期、当前班级已加载的作业，保留教师确认状态、截止时间和“今日无作业”提示。

- 默认手动翻页；“下一屏”先推进长正文，再切换下一项作业，“下一项作业”可直接跳转。
- 正文完整保留。相邻屏重叠一行，避免行尾被分屏边缘遮住；也可直接滚动查看。
- 可调整字号，选择每屏15、20、30、45或60秒后开始轮播。最后一项结束后重新开始。
- 手动滚动或调整字号会停止轮播。通知弹窗、页面进入后台时暂停计时；恢复后重新等待完整间隔。
- 作业发生更正、撤回等变化时停止轮播并回到第一屏，提醒核对；当前范围没有作业，或绑定、日期、班级范围改变时退出。
- 离线时只显示已加载内容并给出提示。组件随 PWA 预缓存，完成应用缓存后断网首次打开仍可用。
- 关闭后恢复原作业板位置。刷新页面后默认退出抄写模式，不自动启动轮播。

## 教师个人作业模板

入口：教师作业编辑器正文下方“个人作业模板”。需要连接支持模板接口的后端，模板跟随当前教师账号同步。

模板保存名称、标题、正文，以及可选的常用需带物品。例如：

```text
名称：练习册
标题：第〔页码〕页练习
正文：完成练习册第〔页码〕页，第〔题号〕题。
```

“填写使用”时填写页码和题号，同名填空项只需填写一次；核对预览后套用到编辑器。若已有标题、正文或物品，会先确认是否替换。套用不发布作业，也不修改科目、班级、作业板日期、发布时间或截止时间。包含物品的模板会要求重新选择携带日期；模板未填写物品时，保留编辑器已有的物品和携带日期。

每个账号最多50个模板。名称最多60字、标题191字、正文6000字、需带物品500字；每个模板最多10种填空项，名称不超过32字。填写后的内容同样检查长度。需要输入纯文本，模板不执行脚本。

修改、删除携带模板版本。两台电脑同时修改时，只接受同一版本的一次修改；另一方显示冲突并保留输入，需核对后返回列表、重新载入。模板编辑和填空期间会阻止应用自动刷新，主动关闭未保存内容时需要确认。账号或编辑对象变化时关闭旧模板窗口，旧请求结果不能进入新编辑器。

## 工程与部署

后端使用已有 `AccountPreference`，键为 `homework-template:<UUID>`，所有操作按已鉴权账号隔离；不接受客户端指定归属账号。新增模板的容量检查在事务内串行化，修改、删除在数据库行锁事务中检查版本并写入。无需新增数据库迁移，也无需修改部署代理。

前后端需要配套更新；旧后端没有接口时模板窗口会显示请求失败，原有作业编辑不受影响。更新后端后可刷新模板重试。

验证入口：

- `pnpm test`、`pnpm lint:check`
- `pnpm test:e2e tests/e2e/copy-mode.spec.js`
- `pnpm test:e2e:fullstack tests/fullstack/homework-templates.spec.js`
- 后端 `node --test tests/homeworkTemplates.test.js`

浏览器回归验证长正文重叠翻页、离线首次打开、轮播及通知暂停、后台恢复和内容更正。全链路测试使用临时 PostgreSQL 和真实账号接口，验证模板同步、填写、替换确认、账号隔离、并发上限和版本冲突。

### 本轮验证结果（2026-09-12）

- 前端单元测试479项通过；后端常规测试178项通过、16项数据库条件测试按原配置跳过。
- 3项契约测试、11项真实 PostgreSQL 全链路测试通过；隔离数据库准备阶段的账号会话撤销测试也通过。
- 浏览器全量118项：首轮117项通过，名单管理旧测试遇到关闭动画期间两个弹窗并存的定位竞争。明确定位离开确认弹窗后，该项连续5次通过；未修改名单业务逻辑。
- Lint、生产构建、PWA构建校验和差异空白检查通过。测试数据库与临时容器已由测试脚本清理。
- 以上为开发电脑上的自动化结果，不代表实际班级大屏的性能实测。本轮未提交、推送或部署。
