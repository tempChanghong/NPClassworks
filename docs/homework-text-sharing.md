# 文字版作业清单

学生页点击“复制文字清单”；班级大屏从“更多 → 复制文字清单”进入。原有打印清单预览也可切换到“文字清单”。

默认勾选全部科目，可以取消不需要分享的科目。核对文字预览后点击“复制文字”，再自行粘贴到班级群。文字版保留班级、日期、内容更新时间、必做、选做、截止时间、提交说明、需带物品以及教师确认状态。“今日无作业”作为明确状态显示，不把缺少记录当作无作业。

文字科目筛选同时作用于作业及需带物品汇总；不改变原有打印、图片清单。假期清单也可从同一组件复制文字。

预览使用打开时的固定快照，和打印共用范围过滤逻辑，不包含通知或本机尚未上传的作业。使用离线缓存时，复制的文字也保留缓存提示；待上传或队列读取异常提示同样保留。需要最新内容时，关闭预览、刷新作业板后重新打开。

若浏览器不支持或拒绝自动复制，页面会提示使用“全选文字”，然后按 Ctrl+C 或使用系统复制菜单。复制失败不会报告成功，预览内容保留。未选择科目时禁止复制。

验证：`tests/homeworkText.test.js` 覆盖文本完整性与科目筛选；`tests/e2e/homework-print.spec.js` 覆盖真实剪贴板、离线打开、手动复制、迟到结果隔离及原有打印和图片导出。
