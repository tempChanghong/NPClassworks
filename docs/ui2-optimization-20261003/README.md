# NPClassworks UI.2：教师端发布与记录

日期：2026-10-03。承接 [UI 综合评审](../../docs/NPCLASSWORKS-UI-DESIGN-REVIEW.md) 的教师端问题。改动只在当前本地 NPClassworks 工作区，未提交、推送或部署。

## 改动

- 低于 1280px 的教师界面按“待处理／新建发布／发布记录”切换。无待处理事项时，首页同时显示简短状态和记录；编辑现有发布会自动切到表单。切换任务不会卸载表单或清空未保存输入。
- 桌面继续并排显示发布表单与记录。教师身份、教学汇总工具和账号操作分层；学校管理、PIN 与退出归入账号菜单。空待处理中心压成简短提示。
- 表单把发布类型、科目、目标、作业板日期和正文放在前面。标题、无作业标记、常用目标、选做、需带、提交、定时和预览继续可用。常用目标与选择说明折叠；快捷输入紧跟正文。
- 发布管理默认呈现全部、待确认、教师已确认和草稿状态；其他状态及类型、科目、班级、日期条件可展开。搜索、状态计数、复用、编辑、撤回及历史入口保留。
- 从记录切换编辑时，如表单有未保存输入，先要求明确确认；取消后输入原样保留。正在保存时，只有当前输入与已提交快照一致，才允许切到另一发布；之后新增的输入不会被静默丢弃。
- 设置页按当前学生／教师／大屏角色加载数据。教师打开设置不再因无学生选班记录而弹出“选择我的班级”。

发布、教师确认、版本冲突、复用日期核对、权限与 NPEP 设备行为均沿用原逻辑。
