# 提示音超时、跨页面确认与折叠测量

## 提示音准备

Web Audio 的恢复、资源下载、响应正文读取和解码受一次播放的 5 秒准备时限约束。下载使用 AbortSignal，挂起的解码或恢复即使随后完成，也不能触发已超时的播放。超时不转入另一次可能迟到的备用播放；缓存失败项会被移除，下一条通知可以重新尝试。正常 Web Audio 不可用或其他错误时仍沿用普通 Audio 回退。

缓存按 AudioContext 隔离，异步准备期间使用捕获的上下文；相同上下文及路径复用正在加载或已解码的结果，旧失败不能删除后续新结果。单元测试分别挂起恢复、下载、正文读取、解码，验证超时、重试、请求取消和迟到结果不播放。

## 已打开页面的确认同步

大屏监听当前绑定的本地确认标记 storage 事件。重新读取当前存储，按通知 ID 和 revision 合并到本页已知确认集合，更新已打开的通知中心和弹窗，不需要关闭再打开，也不需要等待 feed 改变。其他绑定的事件、旧版本确认均不能确认当前新版；无法读取、缺失或损坏的存储不会撤销本页已知确认。组件卸载时移除监听。

新增真实浏览器场景先在未修复代码上复现另一页弹窗不关闭，再验证双页已打开的通知中心、弹窗、新版确认和绑定隔离。

## 折叠性能测量

使用生产构建、Chromium、1440×1000 视口，分别加载 10 和 100 条通知，每条正文重复 40 次。对通知卡片的 `getBoundingClientRect` 计数，折叠后连续进行四次窗口宽度变化，并重新展开验证可见性。

| 通知数 | 展开时 DOM 节点 | 折叠时 DOM 节点 | 折叠动作增加的尺寸测量 | 折叠后四次宽度变化增加的尺寸测量 |
| --- | ---: | ---: | ---: | ---: |
| 10 | 275 | 277 | 10 | 0 |
| 100 | 2615 | 2617 | 100 | 0 |

节点数包含标题、按钮及 Vuetify 交互节点。测量确认隐藏卡片仍保留 DOM，但此场景没有持续发生隐藏尺寸测量；这不是低配设备的内存或 CPU 基准。因此本轮保留 `v-show`，未为未经量化的收益改成卸载卡片。

复测命令：

```sh
pnpm exec playwright test --config tests/benchmarks/playwright.config.js
```

测量结果作为 JSON 附件写入 `test-results/notice-benchmark`。它是独立测量入口，不向普通 Browser CI 添加机器相关耗时阈值。

## 本轮验证结果

- 单元测试：459 项通过，包含四个提示音准备阶段的超时、重试与迟到结果测试。
- 普通 Browser：108 项通过；跨页面确认场景在修复前失败、修复后通过。
- PostgreSQL 全链路：8 项通过，附带的 1 项会话数据库回归通过；使用本机隔离数据库，结束后清理。
- 独立折叠测量：2 个场景通过；Lint 与 `git diff --check` 通过。
