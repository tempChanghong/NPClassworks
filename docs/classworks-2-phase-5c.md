# Classworks 2.0 第五阶段 C：学校管理页面

新增 `/classworks-admin`，与教师工作台使用同一套 OAuth 会话。

页面功能：

- 载入后端维护的七班制组织模板或上传本地 JSON；
- dry-run 展示科目、行政班、走班教学班、授课规则、错误和提醒；
- 预检通过后正式导入；
- 按学校和当前学期查看全部教学空间教师名册；
- 单名教师表单或批量 JSON 分配；
- 区分已登录教师与“待首次登录”邮箱邀请；
- 移除教师成员或取消尚未认领的分配。

模板按当前消息设置一、四班物化生，二班政治，三班物化；五至七班每班各定一个小科，暂用化学、生物、地理表示合计二理一文，导入前仍需按最终名单核对。
