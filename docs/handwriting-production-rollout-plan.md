## 实机验收清单

1. 覆盖大屏及教师的必做、选做，新建、编辑、草稿和复用。测试中文、数字、化学式、页码范围和较长多行，不以生成字体代替真人新笔迹。
2. 测试冷启动、已缓存启动、反复关闭重开、后台中断、两个窗口竞争，确认同一来源最多一个推理 Worker，关闭后无残留任务。
3. 同时记录完整浏览器进程组内存、页面堆、识别全流程和模型阶段的 p50/p95、触控与取消响应。与同设备的现有 r19 候选比较，不凭空设定内存额度，也不强制 GC 或缩短空闲时间制造结果。
4. 未缓存时断网，应提示联网并保留当前内容；已缓存且受 SW 控制时可离线识别。大屏断网保存后刷新、恢复网络，确认只补传一次；教师仍为保存失败后保留当前输入、联网手动重试。
5. 一窗口打开手写，另一窗口换班级凭证或换回原凭证，旧选区均不可复活。关闭重开后重新确认才能保存。
6. 另一设备更新同一作业后，旧草稿不能静默覆盖；明确选择生成新版本或另存，核对原作业、版本历史和离线队列。
7. 更新 PWA 时保留正在录入的正文和草稿，不因组件下载失败而要求丢弃输入。确认后端请求及存储中没有笔迹、图片、候选、特征或模型缓冲。

- 本次手写接入复用既有 `content`、`contentJson.optionalContent` 和保存接口，不需要新建 KV 表或迁移。已使用 KV 当前 `main` 的独立快照通过 22 项真实保存回归；原 KV 分支上的手动自习作业修复属于另一事项，不是手写接口的新增依赖。

- 若需要按学校控制可见性或远程关闭入口，这是单独待确认的配置能力；当前没有为了灰度新增一套学校开关或权限体系。
