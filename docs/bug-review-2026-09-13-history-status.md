# 历史确认入口状态修复（2026-09-13）

本轮继续排查真实交互问题，保留前两轮尚未提交的改动。新增修复仅涉及前端历史窗口及浏览器回归，没有修改后端或部署代理。

## 已复现问题

历史窗口此前仅检查教师模式和 `isCertified`，因此尚未确认的草稿、已撤回内容也会显示“教师确认当前版本”。列表中的确认入口已按展示状态排除这两种内容，历史窗口却未同步约束。

后端 `certifyPublication` 明确要求当前状态为 `PUBLISHED`，否则返回 `PUBLICATION_NOT_PUBLISHED`。因此这是无效操作入口，不是草稿可被绕过发布流程确认的后端漏洞。

浏览器分别打开未确认草稿和未确认的已撤回内容的历史窗口，两项新增用例在修复前均失败：预期没有确认按钮，实际各有一个。

## 修复

`PublicationHistoryDialog.vue` 的按钮显示与点击处理共用 `canCertifyCurrent`：教师模式、当前内容已发布、尚未确认时才可操作。历史列表、分页和历史恢复功能保留；已发布内容的确认流程保持可用。是否有确认权限仍由后端核验。
