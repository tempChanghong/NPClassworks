# NPEP Pre 20261001：网页配套更新

本次主分支更新接入 NPEP 通知、完整考试／日常远程切换、ExamAware 方案控制，以及原生噪音监测、学校年级／班级排程和报告来源。配套 KV 与 NPEduTools 源码也需更新；网页／KV 包版本 `1.1.0` 不能单独代表完整版本组合。

学校后台入口为 NPEP 设备互联；班级大屏从课堂工具进入噪声监测。原生接管后由桌面使用麦克风，网页只控制并展示统计，停用旧网页定时采集，失联不自动退回网页采集。学校排程依赖桌面的 ClassIsland 学校时间。

这是预览版；真实班级大屏与排程现场验收尚未完成。已完成隔离自动测试、网页生产构建／静态 PWA 和部分开发电脑联调；不能据此标记生产验收通过。完整范围及限制见 NPEduTools 仓库的 `docs/releases/Pre-20261001.md`。

本次源码合并到 main 会触发既有部署流水线，流水线完成及服务健康必须另行核对。升级前备份 KV，按完整迁移链应用后端更新，保留 NPEP 身份。上线前核对已保存的年级／班级规则，只先测试一台设备。

本地调试仍使用原生 PostgreSQL，不使用 Docker；参见 [统一启动](local-development.md)。源码检查不扫描 `.artifacts`／`.cache` 生成目录。生产构建后执行 `pnpm pwa:validate`，也可指定隔离输出目录。

自动 Claude 代码审查是可选服务。仓库没有安装 Claude Code GitHub App 或没有配置 API 密钥时，不能执行该审查。默认跳过自动审查；安装 App、在仓库 Secrets 中配置 `ANTHROPIC_API_KEY` 后，可将仓库 Actions 变量 `CLAUDE_REVIEW_ENABLED` 设为 `true` 开启。启用后的服务错误仍正常报失败，不通过忽略错误掩盖问题。单元测试、代码检查、浏览器与跨端契约检查不受此开关影响。历史失败记录会保留。
