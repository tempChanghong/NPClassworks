# 大屏作业临时放大

在大屏上点击一项作业的正文，或点击该卡片的“放大查看”，即可在页面内全屏阅读这一项作业。通知不增加该入口；学生页保持原有阅读方式。

放大视图显示科目、当前班级范围、作业板日期、标题、完整正文、截止时间及教师确认状态。默认字号大于普通卡片，并跟随大屏字号设置；可通过右上角按钮进一步放大或缩小。长标题和正文自动换行，正文区域可独立滚动，关闭按钮保持可用。无作业标记保留其正文，不显示无意义的截止时间。

点击“关闭放大”“返回作业板”或按 Esc 退出。班级和日期未改变时，恢复打开前的页面滚动位置，并把键盘焦点交还给原入口。正文入口可通过键盘聚焦并按 Enter 打开，不影响卡片的修改和历史按钮。

放大视图使用当前大屏已加载的作业，无额外接口请求。收到同一项作业的更正时同步更新内容，并提示核对；该项不再出现在当前有效列表中时关闭视图。切换作业板日期、绑定或教学班范围也会关闭视图，避免继续展示旧范围的数据。缓存及离线状态会明确提示。

组件随 PWA 预缓存，已安装的大屏可以断网后首次放大已缓存的作业。本次不修改后端、数据库结构或部署代理。

浏览器测试位于 `tests/e2e/publication.spec.js`，覆盖完整正文、字号调节、滚动与焦点恢复、实时更正、撤回关闭、离线首次使用和日期范围切换；完整回归继续覆盖编辑、历史、同步和清单导出。
