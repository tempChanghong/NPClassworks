# 先开放班级大屏，再现场配对

1. 学校管理员进入“学校管理 → NPEP 设备互联 → 班级大屏预授权”，开放已有的有效班级大屏。
2. 对应大屏登录 NPClassworks，进入“课堂工具 → 连接 NPEduTools”。这里显示后端服务地址和配对码。
3. 在 NPEduTools 初始设置／学校互联中填写这个地址，检查服务，输入网页配对码。
4. 核对学校、班级、大屏以及连接功能，在本机确认。无需管理员再在线批准。

码为 8 位、10 分钟有效、一次兑换；仅保留在当前页面。重新生成会取消旧的未兑换码。已有设备时不允许覆盖，先由管理员核实并撤销旧登记。

“关闭网页配对”阻止新的申请并使未完成申请失效；已经连接的设备继续使用原授权，断开请用“撤销互联设备授权”。新流程和旧的桌面生成码／管理员逐次批准流程同时保留。

批量入口在同一卡片的“按年级／全校批量设置”：选择范围及开放／关闭 → 预览 → 核对数量和明细 → 勾选确认 → 提交。全校指后台所选的当前有效学期，包含未归入年级的行政班；停用班级、大屏、非行政班及旧学期不参与。只修改已有的大屏，未来新建的大屏不继承授权。超过 50 台时显示前 50 台，提交仍覆盖预览统计的完整范围。

名单或授权在预览后变化，后端拒绝整批保存，刷新并重新预览。已是目标状态的大屏保持授权版本和配对码；已有连接不解绑。切换学校、学期或目标操作会清除预览与确认；提交丢失回执时先刷新实际状态，不能直接重发旧预览。

分离部署时桌面填写后端 origin，如 `https://api.example.org`；本地调试使用实际后端端口，如 `http://127.0.0.1:3000`。页面显示的服务地址取当前前端配置的后端地址，不依靠页面域名猜测。

代码：`NpepPairingAccess.vue` 管理班级授权，`NpepScreenPairingCard.vue` 负责大屏码；共享 `classworksV2Client.js` 隔离账号和大屏凭据。后端需升级并应用 `20261002000000_npep_screen_pairing` 迁移。学校预授权是持续的服务器设置，不依赖临时管理员登录。
