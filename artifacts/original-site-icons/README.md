# 原网站图标素材

这是项目现有图标的原样副本，用于重新设计时参考。没有替换网站正在使用的文件。

优先参考：
- pwa/logo.svg：index.html 引用的 SVG，256×256 viewBox，可编辑矢量。
- source/logo.svg：src/assets 中的另一份矢量源文件，404 页面引用。
- source/cslogo.png：256×256 PNG 图案参考。
- pwa/pwa-512x512.png：512×512 PWA 图标。

现有发布资源：
- website/favicon.ico：浏览器标签页当前引用的 public/favicon.ico。
- pwa/apple-touch-icon-180x180.png：Apple 触摸图标。
- pwa/pwa-64x64.png、pwa-192x192.png、pwa-512x512.png：PWA 各尺寸图标。
- pwa/maskable-icon-512x512.png：PWA 可遮罩图标。
- pwa/favicon.ico：PWA 资源目录中的 ICO 副本。
- source/favicon.ico：src/assets 中的 ICO 文件，保留供比较。

原位置与包内目录的对应关系：
- website/ → public/
- pwa/ → public/pwa/image/
- source/ → src/assets/

未纳入 src/assets/logo.png：它是 Vuetify 标志，并非这里要重新设计的 Classworks 图标。
