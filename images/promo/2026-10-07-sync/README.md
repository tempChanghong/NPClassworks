# NPClassworks「同频」宣传图

2026-10-07。2560 × 1080 横幅，RGB。沿用 NPEduTools「跃迁」的系列构图，以黑铜背景、暖橙光场、玻璃字和三张真实界面截图组成首版；仅保留标题、产品名、组织矢量字和网址。

## 交付

- `NPClassworks-同频.png`：Illustrator 画板导出。
- `NPClassworks-同频.ai`：主要可编辑母版，标志与品牌字为矢量，截图嵌入，辅助文字保留自然字形比例。
- `NPClassworks-同频-分层.psd`：Photoshop 整理的分层工作文件；矢量编辑使用 AI。
- `NPClassworks-同频-PS.png`：由分层 PSD 导出的比对预览。
- `NPClassworks-同频-中间.psd`：Illustrator 直接导出，包含画板外光晕；日常编辑使用带「分层」的裁切版。
- `build-poster.jsx`、`finish-photoshop.jsx`：原生 Adobe 制作脚本。
